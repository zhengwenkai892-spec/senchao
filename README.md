# 森潮GEO搜索拓词（senchao-geo-search-expander）v3.0.0 全域版

森潮全域科技出品的全域 GEO 搜索拓词专家。客户给一个公司全称、品牌简称、官网网址或一段简介，本专家交回一份可直接使用的全域 GEO 搜索词库网页。

## 类型

Agent 型（单个 AI 专家）｜行业分类：营销增长（05-MarketingGrowth）

## 核心能力

- **13 平台分 3 族**：A 通用对话族（豆包/DeepSeek/千问/元宝/Kimi/文心/智谱）、B 生态内嵌族（百度AI/微信小微/夸克）、C 垂类生活决策族（美团/抖音/小红书点点）。分层依据是「用户离成交有多远」与「AI 靠什么内容召回」，不按公司分。
- **双轴意图分类**：意图类型 I1 认知 / I2 选型 / I3 对比 / I4 交易 / I5 服务 / I6 口碑，配「意图 × 平台族」投放优先级矩阵与词量配额。
- **森潮五真体系串联**：真实意图洞察 → 真实信息架构 → 真实语义匹配 → 真实权威背书 → 真实效果验证，每真对应明确的意图层、平台族、词型与验收口径。
- **全域营销漏斗**：L1 认知 → L2 兴趣 → L3 决策 → L4 交易 → L5 复购，词库按层展示，并标出「缺承接内容」的层。
- **三类词分层组词**：品牌词「标识六式」、品类词「品牌前置三句式」、业务词「修饰维度 × 核心品类 × 意图动作」三轴相乘，配 8 模式填充矩阵与本地/B2B 双档配额。
- **四层查重**：字面查 → 结构查（三元组）→ 句式查（防刷屏）→ **跨平台归并查**（同一词只算 1 条 + 多平台标签，防词量虚增 2–3 倍）。
- **三级真实性校验（准入规则）**：S 一手实测 / A 准一手 / B 二手推断（配额 ≤15%，单独成组标灰）/ X 无来源直接删。每条词带来源级别、来源平台、采集日期、原始证据；抽检 10% 回原平台实测，通过率低于 80% 整批回炉。
- **广告法闸门**：绝对化用语、虚假承诺、无实证背书自动识别并给改法。
- **17 行业取值表**：法律、装修、搬家、医美、口腔、财税、教育、餐饮、家政、健身、宠物、汽车服务、婚庆摄影、旅游酒店、房产中介、工业设备、企业服务；未覆盖行业走「兜底三步法」。
- **30 项交付前自检清单**：逐项打勾，打不了勾不许交付。
- **单文件网页交付**：十个板块（板块 0 为头部）+ 一键复制（含 `file://` 兜底）+ 响应式 + 打印样式，零外部依赖。

## v3.0.0 变更说明（相对 v2.0.0）

本次是**战场覆盖升级**。v2 解决的是「词库质量」——不凑数、不重复、不编数据；v3 解决的是「只盯 AI 对话框，漏掉了用户真正做决策的入口」。

| # | 变更 | 原因 |
|---|---|---|
| 1 | 平台从 7 个扩到 13 个，分 3 族 | 原 7 个全是 AI 对话平台，漏掉美团、抖音、小红书、微信、百度搜索、夸克这六个用户真实决策入口 |
| 2 | 新增双轴分类（意图 × 平台族） | 单轴分类无法回答「这个词该投哪个平台」 |
| 3 | 新增森潮五真体系对应 | 让词库与方法论挂钩，每层词有明确的验收口径 |
| 4 | 新增全域营销漏斗 L1–L5 | 客户真正关心的是「我缺哪一层」，不是词有多少条 |
| 5 | 查重从三层扩到四层，新增跨平台归并 | 加 6 个平台后最大风险是同一个词被拆成 6 条，词量虚增 2–3 倍 |
| 6 | 「标注推断」升级为「来源可追溯」 | 从「可以推断」收紧为「推断有配额上限 + 必须留痕 + 抽检复核」 |
| 7 | 词库表新增 6 个字段 | 平台标签、意图层、漏斗层、五真环节、来源级别与采集信息、承接现状 |
| 8 | 自检清单 21 项 → 30 项 | 覆盖平台标签、跨平台归并、来源级别、B 级配额、抽检记录、五真对应、漏斗空层 |
| 9 | 方法论主体统一为「森潮全域科技」 | 原技能包署「森潮互动」，与公开资料主体不一致 |

**方法论口径说明**：

- 正式名称：**森潮五真体系**，归属 **森潮全域科技**
- 已确证四真：真实意图洞察、真实语义匹配、真实权威背书、真实效果验证
- 第 2 项「真实信息架构」**标注【待公司确认】**，依据行业白皮书所列五环节中的「信息架构搭建」；技能包内只在一处定义，确认后改一处全局生效
- ⚠️ 另有一套「真商机/真产品/真链路/真转化/真验证」属**别家**方法论，与本体系无关，严禁混用
- 旧称「GEM 五真体系」在百科等对外资料中仍存在，需同步更新以免口径不一

**脚本 `expander_prep.py` 同步升级**：

| 新增能力 | 说明 |
|---|---|
| `--quota-b 15` | 校验 B 级推断词占比，超限报警 |
| `--check 50,50,120` | 分类数量校验（沿用 v2） |
| 跨平台变体检测 | 自动识别「成都装修公司哪家好 豆包」这类把平台名写进词的错误写法；「成都抖音代运营」这类合法业务词不会误报 |
| 10 列全字段解析 | platform / intent_layer / funnel_layer / truth_layer / source_level |
| 列数异常警告 | 防「少写一个逗号导致来源级别静默错位」 |
| 来源级别统计 | S/A/B 占比 + 未标提醒 |

v2 已修复的问题（P0 识别、地域误判、强意图词降级、电商误命中、GBK 控制台崩溃）全部保留。

## 使用示例

- 帮我基于【公司全称/官网】生成全域 GEO 搜索词库，合并成一个 HTML 网页。
- 先拿【某公司】做个样板，我确认口径后再批量套用到其他商家。
- 在这版词库上加竞品缺口板块，列出竞品覆盖而我们没有的词。

## 口径来源

三类组词公式与业务词矩阵参考行业通行的 GEO 词汇定义与挖掘方法；13 平台收录逻辑基于各平台公开产品定位，属**工作假设**，非实测结论；热度只给档位，不提供未经实测的搜索量数字。五真体系表述以公司口径为准。页面上所有推断内容都会标注来源与级别。
